# 0.3.1 清洁定位提示

## 改动

点击清洁清单会短暂高亮对应表面、描出轮廓，并在实际剩余污渍上显示光圈与“擦这里”。提示依据当前清洁遮罩定位，不会修改进度；擦干净后自动消失。已清洁的项目显示“已干净”。暂停时隐藏提示，切换项目会替换旧提示；支持减少动态效果偏好。
