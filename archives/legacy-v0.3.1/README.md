# 第一季 v0.3.1 历史归档

这份快照保留独立项目建立之前的第一季源码、文档和 QA。正式仓库的初始提交已包含两季，旧版有部分文件内容不在原有 Git 历史中，因此单独保存当时的完整文件。

归档排除顶层依赖、构建目录、运行记录与 Git 元数据，保留 QA 中既有的历史回滚压缩包。manifest.json 列出每个文件的字节数与 SHA-256，压缩包已经实际解包并逐文件比对，原目录亦重新校验一致。

恢复到一个新的空目录：

```sh
tar -xzf quiet-workshop-v0.3.1-source-and-qa.tar.gz -C <empty-directory>
cd <empty-directory>/quiet-workshop-v0.3.1
npm ci
```

当前游戏继续在正式项目根目录维护。本归档不参与现有游戏构建或线上发布。旧演示目录路径仍保留，方便定位早期演示与拍摄资料。
