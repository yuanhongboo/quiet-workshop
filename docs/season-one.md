九处日常，三段小故事。擦洗、整理、修复，把亲手照顾好的物件带回同一家小店，最后重新开门。

## 玩法与存档

- 按住鼠标或手指拖动擦拭；点击清洁清单会高亮对应部位，并用“擦这里”光圈标出实际剩余污渍。手机镜头仍会靠近选中的区域。
- 拖动物件到对应光圈，松手归位。有拾取和吸附容差，错误放置会提示并保留进度。
- 修剪与缝扣可点实物或任务按钮。浇水、开帘、抛光按住进行、松手暂停；也可聚焦按钮后按住空格或回车。
- 钟表拖动滑条校时；招牌要在牌面实际拖动刷涂，字牌遮挡的区域不计入目标。
- 前八关自由选择；第九关在前八处全部恢复后开放。选择页和完成页都能进入“小店全景”。
- 每关当前进度独立保存；整季收藏记录会保留已完成的成果，重玩不会撤掉店里的物件。
- 旧版咖啡和四关版本的进度可直接接续。清除浏览器数据会清除本地进度，跨设备没有云同步。
- “找回未归位器具”只重置松散物件；已完成的清洁、归位和收藏会保留。
- 没有倒计时、扣分、货币消耗或限时季期限。

## 开发

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

默认端口 4188。构建包位于 `dist/`，使用相对资源路径，可在任意 HTTPS 子目录运行。第三方许可随包发布。

- `src/season.mjs`：本季主题、三章九关和开店条件。
- `src/levels.mjs`、`restoration-levels.mjs`、`finishing-levels.mjs`、`shop-level.mjs`：关卡数据。
- `src/core.mjs`：清洁遮罩、阶段流和旧存档校验。
- `src/task-actions.mjs`：点击、长按、滑条、刷涂的任务规则。
- `src/action-controller.mjs`：任务输入、松手/取消、进度 UI。
- `src/progress.mjs`：独立存档、累计收藏、旧版迁移与第九关解锁。
- `src/scene.mjs`、各 `*-scenes.mjs` / `shop-scene.mjs`：模型、材质、镜头与开店收尾。
- `src/physics.mjs`：刚体、抓取、辅助归位和失稳回收。
- `src/audio.mjs`：程序合成的清洁、修复、浇水、滴答与原创唱片旋律。

`?diagnostics` 在页面 DOM 中显示阶段、任务、收藏、物件投影和运行数据。请在独立测试端口进行 QA，以免覆盖玩家进度。手工输入验证页面只保存在 QA 目录，不进入发布清单。

## 边界

本季全部模型、纹理、插画与音效由代码生成，没有新增外部美术或音乐下载。松散物件使用 Rapier 刚体；归位有辅助动画，水流、植物生长和钟表联动是面向玩法制作的效果。

本季的浏览器尺寸检查不等于真实手机硬件性能认证，也不能证明玩家留存或商业表现。旧版记录保留在 `qa/filter-recovery-v0.1.1/` 与 `qa/multilevel-v0.2.0/`。

0.3.1 清洁定位提示的验证记录见 `qa/cleaning-hints-v0.3.1/REPORT.md`。
